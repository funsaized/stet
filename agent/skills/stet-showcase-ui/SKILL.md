# Stet showcase UI

Choose the few product features that serve the requested story. Inspect real
UI behavior and avoid unsupported claims. Establish one focal point, then use
subordinate callouts with short copy. Circles draw attention, highlights anchor
words, arrows express relationships and notes add context. Do not use all
primitives merely to show the library.

Leave space around controls and let the product remain usable. Reuse the app's
palette while checking actual text contrast. Still drawings are the default;
only add motion when it serves the requested presentation and respects reduced
motion. Fixed seeds support reproducible presentation review.

Use the [base Stet workflow](../stet/SKILL.md) to query installed APIs, form and
validate a plan, and adapt canonical framework snippets. Verify desktop/mobile
composition, scrolling, navigation cleanup and live control behavior. Remove
callouts that compete with the primary story or obscure the product.
