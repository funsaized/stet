# Primitive selection

Use `stet inspect --json` for the installed primitive list, options, required
fields, defaults, target arity and imports. `stet schema annotation-plan` gives
exact structure. Read `stet snippet <primitive> --framework <framework>` before
editing. Do not add unsupported options such as sticky width, arrow side, or a
runtime target selector. Core mark kind is a separate argument; snippets show
how each adapter represents it.

Choose a circle for a focal element, underline for words, highlight for a passage,
arrow for a relationship, sticky for concise explanation, and mark for a justified
right/wrong verdict. These are choices of emphasis, not changes to UI semantics.
Several small marks usually communicate less than one clear focal mark and note.

The capability option schema reflects accepted TypeScript fields. Read `effects`
as well: some shared options are accepted but have no visible effect on a given
primitive. Required authoring text must be nonblank. No preset called “danger”
or “onboarding” exists; reason about intent and use actual supported fields.
