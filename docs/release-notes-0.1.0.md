# Stet 0.1.0 — proposed release notes

Stet's optional agent authoring tools now expose installed capabilities, validate
source-target plans and provide copyable integration examples while preserving
the existing annotation API and application-owned controls.

- Actionable plan diagnostics, source-derived schemas and deliberate drift checks.
- Recoverable project skill installation with local-edit protection.
- Read-only project/framework evidence and a settings-plan starting example.
- Thirty primitive snippets and five lifecycle patterns that keep controls present
  when annotations are disabled or arrow destinations change.
- Rendered framework lifecycle, SSR/client, WebKit and packed Linux/Windows CLI
  verification. Runtime size budgets and zero required dependencies are unchanged.

Plans and compiler checks do not establish live UI correctness. Source, interaction
and screenshot review remain necessary. The release decision is pending the fresh
agent trials documented in agent-evals.md; this draft does not claim those pass.
