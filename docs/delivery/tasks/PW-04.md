# PW-04 — Add sessions and locator attachment
## Outcome
Owned sessions attach supported annotations to one live target. **Parent:** D2/D3. **State:** BLOCKED.
## Prerequisites
PW-03 accepted.
## Required reading
Playwright contract/API, helper source, runtime primitive signatures.
## Allowed edits
Helper/bridge and dedicated integration tests.
## Exact change
Resolve exact-one locators, validate documents, own handles/resources, and roll back partial failure.
## Acceptance criteria
Missing/ambiguous/detached/wrong-document differ; races do not silently substitute targets; sessions coexist with source marks.
## Verification
Dedicated page/frame/mixed-ownership integration tests.
## Forbidden scope
Auto rediscovery/reinjection, cross-document arrows, global overlay deletion, commit/push/publish.
## Stop conditions
Stop if target identity cannot be maintained with the accepted API.
## Review evidence
Positive/negative locator matrix.
